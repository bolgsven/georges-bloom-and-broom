# George's Bloom & Broom

Website prototype for a local garden-care business. Built as a static site suitable for GitHub Pages.

## Files

- `index.html`: website entry point (must be at the repository root)
- `styles.css`: responsive website styles
- `script.js`: navigation, interactive garden, enquiry preview and mower scrollbar
- `config.js`: contact configuration (the contact email is intentionally blank)
- `assets/`: bundled images, logo and service examples

## GitHub Pages

Publish from the `main` branch and `/(root)` folder in **Settings > Pages**.
The site's expected project URL is `https://bolgsven.github.io/georges-bloom-and-broom/`.

## Before launch

The garden scene and before/after images are illustrative, not evidence of previous work. The service list must be confirmed with George. The enquiry form is in demonstration mode until contact information is set up; no messages are sent from this preview.
